Operator checklist:
  - Ensure a default StorageClass exists in this cluster, OR set
    taskpods.persistence.storageClass explicitly to a named class.
  - Set a namespace ResourceQuota on {{ include "poiesis.taskpodNamespace" . }}
    to cap aggregate PVC count + storage:
        kubectl -n {{ include "poiesis.taskpodNamespace" . }} apply -f - <<EOF
        apiVersion: v1
        kind: ResourceQuota
        metadata:
          name: poiesis-taskpods
        spec:
          hard:
            persistentvolumeclaims: "200"
            requests.storage: "2Ti"
        EOF
  - For Velero/Kasten backups, add the backup annotation to
    taskpods.persistence.annotations.
  - For audit-retention deployments, set
    taskpods.persistence.retainAfterSeconds: null and provision an
    out-of-band cleanup process.
